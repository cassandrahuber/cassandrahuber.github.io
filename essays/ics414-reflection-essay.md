# Snack Stack

This semester in ICS 414, I worked on **Snack Stack**, a full-stack web application for managing pantry items, shopping lists, and recipes. My work on this project was more technical than just adding small features. I worked on validation, database-related fixes, form behavior, testing setup, CI workflow, search functionality, and making different parts of the site more consistent with each other. I also helped lead the group by creating the user stories, setting up most of the milestone project boards, and keeping the project moving when tasks needed to be completed.
